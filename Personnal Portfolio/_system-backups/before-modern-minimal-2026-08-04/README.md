# Full System Backup

This folder contains the complete active website from before the modern minimalist redesign.

It includes the landing page, portfolio page, all three project pages, scripts, shared styles, and the previous brutalist portfolio layer. Copy these files back to their matching locations to restore that version.

The modern redesign is isolated in `landing.css`, `landing-motion.js`, and `portfolio-modern.css`, with only stylesheet references changed on the portfolio and project pages.
